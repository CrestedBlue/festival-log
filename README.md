# 페스티벌 로그

페스티벌 타임테이블, 찜한 공연, 현장 지도(GPS)를 기록하는 PWA입니다. 앱스토어 없이 링크 하나로 안드로이드와 아이폰에 설치할 수 있습니다.

## 기능

- **타임테이블**: 스테이지 × 시간 그리드. 공연을 탭하면 ★ 찜이 되고, 찜한 공연끼리 시간이 겹치면 표시됩니다. 자정을 넘기는 공연(예: 23:30–01:00)도 같은 날로 처리합니다(새벽 6시 기준).
- **NOW 표시**: 지금 공연 중인 팀과 다음 찜 공연까지 남은 시간을 보여줍니다.
- **지도 + GPS**: OpenStreetMap 지도 위에 내 위치, 스테이지·화장실·만남 장소 같은 핀을 표시하고 거리순으로 정렬합니다. 한 번 본 지도 타일은 저장되기 때문에 현장에서 신호가 약해도 보입니다.
- **일괄 입력**: `18:30-19:40 아티스트` 형식으로 여러 줄을 붙여넣으면 한 번에 등록됩니다.
- **친구와 공유**: 페스티벌을 JSON 파일로 보내고 가져올 수 있습니다. 찜 목록은 각자 따로 저장됩니다.

데이터는 각 기기의 브라우저(localStorage)에만 저장됩니다. 서버는 없습니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 단위 테스트
npm run build      # dist/ 에 배포용 파일 생성
npm run preview    # 빌드 결과(서비스워커 포함) 확인
```

## 배포 (GitHub Pages, 무료)

1. GitHub에 새 저장소를 만들고 이 폴더를 push합니다.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
3. `main`에 push하면 `.github/workflows/deploy.yml`이 테스트, 빌드, 배포를 자동으로 진행합니다.
4. 배포된 주소(`https://<아이디>.github.io/<저장소>/`)를 친구들에게 보냅니다.

Vercel이나 Netlify에 올려도 됩니다. 루트 경로에 배포하면 `BASE_PATH`를 설정할 필요가 없습니다.

## 폰에 설치하기

- **안드로이드(Chrome)**: 주소 열기 → 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
- **아이폰(Safari)**: 주소 열기 → 공유 버튼 → "홈 화면에 추가"

GPS는 HTTPS 주소에서만 작동합니다. 같은 와이파이의 `http://192.168...` 주소로 접속하면 위치 기능이 막히니, 폰에서는 배포한 주소로 테스트하세요.
