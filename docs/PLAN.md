# festival — PLAN

> 페스티벌 기록 PWA(festival-log) — 타임테이블·지도·GPS, GitHub Pages 배포

## 문제

본인과 친구들이 페스티벌 현장에서 쓸 기록 앱이 필요하다. 요구 기능은 공연 타임테이블, 지도와 GPS 위치 표시.
구글플레이 없이 배포해야 하고, 친구 중 아이폰 사용자가 있을지 아직 모른다.
현장은 사람이 몰려 모바일 신호가 약하다.

## 접근

- **PWA**로 만든다. 링크 하나로 안드로이드·아이폰 모두 홈 화면 설치가 되고, 스토어 심사·비용이 없다.
  APK 직접 배포는 안드로이드만 되고, 아이폰 네이티브 배포는 앱스토어 없이는 사실상 불가하다.
- **서버 없음.** 페스티벌(일정·핀·주의사항)은 **관리자가 앱 안의 카탈로그**(`src/data/catalog/`)에 넣고 push 한다(관리자 UI 없음). 각 기기 localStorage 에는 **유저 데이터만**: 고른 페스티벌 ID, 보고 있는 페스티벌, 찜, 내가 꽂은 핀, 티켓 링크. 권한 표기: (관리자) = 관리자만 수정, (유저) = 유저가 수정.
- 지도는 **페스티벌 공식 지도 그림을 실제 좌표에 맞춘 이미지** 위에 GPS 위치·핀만 띄운다(Leaflet `imageOverlay`, 실제 지도 타일 없음).
  - 공식 지도 그림은 축척이 없고 실제와 방향이 틀어져 있다 → 그림은 그대로 쓰되, **실제와 어긋난 부분은 실제에 맞춘다**:
    OpenStreetMap 지형(공원·호수·건물·길)을 공식 지도 색으로 그린 바탕 위에, 공식 지도의 구역 그림을 잘라 실제 위치에 붙인다.
  - 이미지 범위는 행사장 + 근처 역 출구(몽촌토성역 1번, 올림픽공원역 3번)까지. 확대·축소 가능.
  - 이미지는 스크립트로 생성해 앱에 넣는다(앱에 같이 저장돼 오프라인에서도 보인다). 지도 이미지가 없는 페스티벌만 OSM 타일을 쓴다.
- 지도 아래 핀 목록은 접었다 펼 수 있다. 행사장 위치를 지도에서 저장하는 기능은 두지 않는다.
- 유저는 일정을 입력·수정하지 않는다. 관리 탭의 페스티벌 목록에서 골라 추가한다. 페스티벌 id 는 UUID 이고, 공연·핀 id 는 페스티벌 키(예: `gmf2026`)를 접두사로 고정해 업데이트해도 찜이 유지된다.
- 화면: 타임테이블(스테이지×시간 그리드, 찜·겹침·NOW 선, 스테이지 최소 3개 보임) / 지도 / 정보(티켓 링크·주의사항) / 관리(페스티벌 목록).

## 설계 제약

- GPS(`geolocation`)는 **보안 컨텍스트(HTTPS/localhost)** 에서만 동작 → 폰 테스트는 배포 주소로 한다(LAN http 불가).
- 정적 호스팅이라 응답 헤더를 못 건다 → CSP 는 빌드 시 `<meta>` 로 주입(개발 모드는 HMR 때문에 제외).
- 타일·폰트는 CORS 요청으로 받아 불투명(opaque) 응답 캐시를 피한다 — opaque 는 저장 할당량을 크게 잡아먹는다.
- 가져온 파일은 신뢰하지 않는다: 스키마 검증이 throw 하지 않아야 하고, 기간 밖 공연·중복 id·없는 스테이지 참조를 거부한다.

## 알려진 대가

- 기기 간 동기화 없음 — 폰을 바꾸면 파일로 옮겨야 한다. 친구 간 찜 공유 없음.
- iOS PWA 는 백그라운드 위치·알림이 제한된다.
- 프리셋의 일부 값은 추정이다(끝 시간이 공지되지 않은 마지막 공연, 공식 지도 일러스트에서 위치를 짐작한 핀).
- 지도 이미지의 일부 구역(Radar·Hungry Zone·Art Zone·티켓 부스)은 실측 위치가 없어 공식 지도의 배치를 보고 실제 지형에 끼워 넣은 추정이다.
- 지도 그림을 바꾸려면 생성 스크립트를 다시 돌려야 한다(이미지를 직접 고치지 않는다). 페스티벌마다 지도 이미지를 새로 만들어야 한다.
- 공식 지도 그림은 주최 측(민트페이퍼·MPMG) 저작물이다. 공개 저장소에 들어간다.

## 검증 기준

- `npm test`(lib·data 계층 커버리지 80% 이상), `tsc --noEmit`, `npm run build` 통과.
- 배포 주소에서: 서비스워커 활성, 타일·폰트 런타임 캐시 생성, 콘솔 에러 없음.
- 실기기(안드로이드·아이폰)에서 설치, GPS 권한, 오프라인 지도 동작.
