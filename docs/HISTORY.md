**진행 내용**

- **예방한 결함**(코드 리뷰 + 브라우저 실측으로 발견):
  - zod 객체 단위 `refine` 은 필드 검증이 이미 실패해도 실행된다 → 잘못된 시간(`25:99`)이 든 파일·저장 데이터가 throw 해서 앱이 하얀 화면이 될 수 있었다. 검증 함수를 throw 하지 않게 바꾸고, 로드·가져오기를 try/catch 로 감쌌고, ErrorBoundary 를 추가했다.
  - Workbox `urlPattern` 에 설정 파일 변수(`OSM_TILES`)를 쓴 함수를 넣었더니, sw.js 로 직렬화되면서 변수가 사라져 **타일 오프라인 캐시가 전혀 동작하지 않았다**. 생성된 `dist/sw.js` 를 직접 보고 발견했다. 자급식 정규식으로 바꾼 뒤 `osm-tiles` 캐시가 생기는 것을 확인했다.
  - 타일을 no-cors(opaque)로 캐시하면 브라우저가 할당량을 부풀려 계산한다 → `crossOrigin` 타일과 `statuses:[200]` 로 변경.
  - 새벽 06:00 경계에 걸친 공연(04:00–06:00)이 거부되던 문제 → 시작 기준으로 끝 시각을 굴리고, 12시간 상한으로 역순 입력을 걸러낸다.
  - 손상 데이터의 백업 쓰기가 실패해도 샘플로 덮어쓰던 문제 → 백업에 실패하면 그 세션은 메모리에서만 실행한다.

- 공개 저장소라 커밋 작성자를 저장소 로컬 noreply 메일로 설정했다(전역 설정은 회사 메일).

  - 실측: 공식 지도는 실제 대비 돌아가 있다. 실제로는 88잔디마당(Mint Breeze)이 서쪽, KSPO DOME 이 그 동쪽 약 200m, 88호수 수변무대가 잔디마당 북쪽 약 240m, 올림픽수영경기장이 북동쪽이다.
  - 구현: OSM 지형을 공식 지도 색(바탕 #e1dfc6, 공원 #adcf85, 길 #ebe6e2)으로 그린 바탕 위에, 공식 지도의 구역 그림을 잘라 실제 좌표에 붙이는 생성 스크립트(`scripts/map/`). 잘라낼 때 바탕색(베이지·공원 초록·길 회색)을 투명 처리한다. 잔디마당·KSPO DOME 은 실제 건물 모양을 구역 색으로 칠해 그림과 이어지게 했다.
  - 추정: Radar·Hungry Zone·Art Zone·티켓 부스는 실측 위치가 없다. "한얼광장"은 OSM 에 없다. Art Zone·티켓 부스는 공식 지도 배치대로 잔디마당 남쪽~우리금융아트홀 북쪽에 두었다. Radar 는 처음에 동쪽(성내천 위)에 두었다가, 공식 설명("KSPO DOME–수영장 사이")에 맞춰 두 건물 사이(약 57m 틈)로 옮기고 축소했다.
  - 지하철 출구: OSM `subway_entrance` 노드 기준 몽촌토성역 1번 출구 37.517706,127.113286, 올림픽공원역 3번 출구 37.516172,127.130716. 지금 프리셋 핀은 출구 옆 버스정류장 좌표라 교체 대상이다.
  - 데이터 취득: Overpass API 미러 3곳(overpass-api.de, private.coffee, maps.mail.ru)이 이날 500/502/504 로 실패해서, OSM 공식 API `api.openstreetmap.org/api/0.6/map?bbox=…` 로 받았다(노드 7227, 웨이 741). 저장소에는 필요한 태그만 남긴 `map-src/gmf2026/osm.json`(ODbL, 출처 표기 필요)을 둔다.

- **지도 이미지 방식 구현(앱)**: 지도 이미지는 사용자 데이터·스키마 밖(`src/features/map/festivalMaps.ts`, 페스티벌 id 기준)에 둔다. 가져온 파일이 이미지 주소를 넣지 못하게 하려는 것이다. 이미지 범위 밖으로는 이동할 수 없고, 축소는 이미지 전체가 보일 때까지만 된다. 처음 열 때는 이미지가 화면을 꽉 채우는 배율로 연다(위아래 빈 띠 방지). 핀 패널은 기본 접힘이고 기기별로 기억한다. GPS 가 이미지 밖이면 "행사장까지 N km" 안내를 띄운다.
  - 예방한 결함: 이미 GMF 를 넣은 기기는 예전 핀(버스정류장 좌표, 옛 추정 위치)이 그대로 남아 새 지도와 어긋난다. 앱 시작 시 프리셋 핀만 새 값으로 바꾸는 `syncPresetPins` 를 넣었다. 사용자가 추가한 핀은 남기고, 사용자가 지운 프리셋 핀은 프리셋이 바뀌지 않는 한 되살리지 않는다.

    - 틀렸던 가설: 처음에는 한얼광장을 몰라서 Art Zone 을 88잔디마당 남쪽(벨로드롬 근처)에 두었다. → 한얼광장으로 옮기고 "(대략)"을 뗐다. 티켓 부스는 공식 배치대로 Art Zone 아래, 올림픽공원역 쪽(핸드볼경기장 동쪽)으로 옮겼다(여전히 추정).
    - 수변무대는 그림의 가운데가 아니라 **그려진 무대**를 실제 무대 점에 맞춘다. 가운데를 맞추면 객석이 호수 위로 나간다.
  - **지도 출처 표기**: OSM(ODbL)은 출처 표기가 조건이라 없앨 수 없다. 공식 지도 그림 출처는 의무가 아니다. 사용자가 지도 위 출처 줄을 원하지 않아서, 평소에는 지도 구석의 ⓘ 버튼만 두고 누르면 펼쳐지게 했다(OSM 표기 안내가 허용하는 방식으로 판단). 이미지 지도에서는 Leaflet 기본 출처 줄을 끈다. OSM 타일 지도는 기존 출처 줄을 유지한다.
  - 생성기 JSON(범위·초기 화면·핀 좌표)은 앱에서 검증한다(`parseMapMeta`). 재생성이 잘못되면 지도가 깨지는 대신 바로 오류가 난다.

  - PWA 아이콘: `@vite-pwa/assets-generator` minimal-2023 프리셋은 maskable·apple 아이콘에 흰 여백을 넣는다. icon.svg 를 꽉 찬 어두운 배경 + 안전 영역 안 로고로 만들고, 프리셋의 padding 을 0, 배경을 #1c1726 으로 덮어써서 해결했다.

- **지도 다시 그리기(사용자 지시, 진행 중)**: 공식 그림을 실제 위치에 붙인 결과가 "88잔디마당 모양을 무시하고 동그라미를 박아 넣은 것 같다"는 평가를 받았다. 그래서 공식 그림 붙이기를 버리고, 구역을 실제 모양 위에 직접 그리기로 했다. 88잔디마당은 OSM 의 실제 원두콩 모양 위에 STAGE, STANDING, PICNIC ZONE, SUB/MAIN GATE, HUNGRY ZONE 을 배치한다(사용자 손그림 배치를 따름). KSPO DOME 은 원 위에 STAGE 와 GATE 2-1/2-2/2-3, 수변무대는 무대·객석·GATE 로 그린다. ART ZONE, HUNGRY ZONE, RADAR, TICKET BOOTH 는 색칠한 영역과 이름표로 그리고, 지하철 출구는 노선 배지로 표시한다. 사람·너구리 같은 장식은 뺀다. 이름표는 첫 화면(약 1.3 m/화면px)에서 읽히는 크기로 맞춘다. 첫 화면은 무대 3곳이 한 번에 보이고, 축소하면 역까지 보인다(사용자 확인: 이 화면 구분은 좋다).
  - 공식 지도 마커 34개는 링 모양(흰 원 + 어두운 아이콘)으로 자동 검출해서 30개를 찾고, 오검출 4개를 빼고 놓친 것을 눈으로 더했다. 마커를 지우는 보정(inpaint)은 만들었다가 구역을 직접 그리기로 하면서 필요 없어져 지웠다.

- **잔디마당 윤곽**: 사용자가 "쪼글쪼글하다", "실제 지도에서 누끼를 따 달라"고 했다. 사용자 캡처(상용 지도)에 OSM 윤곽을 겹쳐 보니 위치·모양은 일치했다(대조점 4개, 잔차 ≤5px). 그래서 상용 지도나 위성 사진을 잘라 쓰는 대신(라이선스상 재배포 불가) 같은 윤곽을 단순화(RDP 5px)하고 둥글게(Chaikin 4회) 다듬었다.
- **공식 마커 → 핀(구현)**: 마커 34개를 구역마다 공통 기준점(무대·게이트·피크닉존 등)으로 최소제곱 아핀 맞춤해서 다시 그린 지도로 옮겼다(`scripts/map/marks.mjs`). 잔디마당 안 마커는 실제 잔디마당 안으로 당기고, 이름표 위에 떨어진 마커는 이름표 아래로 내린다. 흡연구역(수영장 건물 위에 떨어짐), RADAR, Hungry Zone 안 2개, 손목밴드 교환은 손으로 놓았다.

- **라인업 단계 추가(사용자 지시, 같은 날)**: 첫 화면 우선순위를 타임테이블 → 라인업 → 지도로 바꿨다. 탭 이름은 "타임테이블" 그대로 두고, 타임테이블 데이터가 없으면 그 자리에 라인업 포스터를 보여 준다. 포스터는 발표 순서대로 아래로 이어 붙여서 스크롤한다. 히어로 락페 1차 라인업 포스터(사용자 제공, 700×880 webp)를 그대로 넣었다. 스스로 내린 판단: 포스터 글자를 화면 낭독기가 읽을 수 있게 alt 에 아티스트·날짜·장소를 적었다. 레이아웃이 밀리지 않게 크기를 지정했다. 첫 포스터만 바로 불러오고 나머지는 스크롤할 때 불러온다. 서비스워커가 미리 저장해서 오프라인에서도 보인다. 관리자 페이지의 타임테이블 보기도 같은 규칙을 쓴다. 확인: 테스트 132개, 375px 앱(주소 없이 열면 라인업), 1440px 관리자 페이지.
- **알림 팝업 밀어서 치우기 + 남은 시간 막대(사용자 지시, 같은 날)**: 알림을 옆으로 끌어 치울 수 있게 했다. 바닥에는 자동으로 닫힐 때까지 남은 시간을 보여 주는 3px 막대를 넣었다. 스스로 내린 판단: 끄는 동안은 남은 시간을 멈췄다가 놓으면 이어서 센다. 세로로 끌면 화면 스크롤로 넘긴다. 오류 알림은 원래 자동으로 닫히지 않으므로 막대를 넣지 않았다. 동작 줄이기 설정에서는 막대를 숨긴다. 막대는 transform 으로만 움직인다. 예방한 결함: 알림의 닫기(✕) 아이콘에 크기가 없어 원래부터 보이지 않았다. 크기를 줘서 보이게 했다. 확인: 테스트 138개. 375px 화면에서 막대가 줄어드는 것, 길게 끌면 사라지는 것, 짧게 끌면 제자리로 돌아오고 이후 자동으로 닫히는 것, ✕ 로 닫히는 것을 확인했다.
- **지도 정보를 페스티벌 코드 단위로(사용자 지시, 같은 날)**: "맵 저장정보 같은 것은 연도에 묶이지 않은 페스티벌 고유 정보로" 라는 지시에 따라 장소·그림 지도·지도 핀을 연도에서 떼어 냈다. 지도 핀은 구역, 공식 마커, 역 출구다. 페스티벌 코드 단위 정보는 `src/data/catalog/series/` 에 있다(`gmf`, `herorock`). 연도 파일에는 이름·날짜·스테이지·공연·주의사항·라인업만 남았다. 그림 지도는 코드로 찾는다(`seriesMapFor(코드)`). 지도 파일과 스크립트 이름도 `gmf2026` → `gmf` 로 바꿨다. 이름을 바꾼 스크립트를 다시 돌려서 webp·json 이 바이트까지 같은 것을 확인했다. 지도 핀 id 는 `gmf2026-zone-*` → `gmf-zone-*` 로 바뀌었다. 핀 id 는 저장되지 않아서 기존 사용자 데이터에는 영향이 없다. 찜(공연 id)은 연도 코드 그대로다. 스스로 내린 판단: 사용자가 꽂은 핀은 지시 범위가 애매해서 연도 단위로 그대로 두고 결정 항목으로 남겼다. 확인: 테스트 140개, 375px 화면에서 GMF 그림 지도와 핀 42개가 전과 같이 보이는 것을 확인했다.
  - 사용자 결정: 내가 꽂은 핀은 지금처럼 연도(회차) 단위로 둔다.
- **펜타포트 2026 타임테이블(사용자 지시, 같은 날)**: 사용자가 준 인스타그램 게시물(@pentaportrf, 2026-07-09)을 로그인 없이 브라우저로 열어 읽었다. 가입 안내 창은 닫고, 사진 7장(표지, 한국어 3일치, 영어 3일치)은 원본 크기로 확대해서 읽었다. 한국어 표를 기준으로 영어 표와 맞춰 봤고, 팀 수가 게시물 본문의 66팀과 맞는 것을 확인했다. 스스로 내린 판단: 표 안에 있는 무대 행사(개막 행사, 스탠리와 함께하는 펜타로빅 with 김혜선)는 공연과 같은 줄에 넣고, id 를 `-event-` 로 구분했다. 무대가 아닌 메인 쿨존 프로그램과 드리머부스, 입장 시간은 주의사항으로 넣었다. 'Curated by' 표시는 뺐다. 무대 이름은 두 줄 제목에 들어가게 줄였다(KB국민카드 / MONSTER ENERGY / STANLEY 1913). 장소는 OSM 의 공원 윤곽 중심점이다. 역 핀은 공원 가장자리에서 직선거리로 가장 가까운 송도달빛축제공원역 4번 출구(약 280 m)다. 그림 지도가 없어서 OSM 타일 지도로 보인다. 확인: 테스트 147개, 375px 에서 3일치 표, 무대 제목, 밤 시간대 행사를 확인했다.
- **찜 겹침 표시 제거(사용자 지시, 같은 날)**: 락 페스티벌은 무대 사이를 오가며 보는 게 보통이라, 찜한 공연끼리 시간이 겹쳐도 표시하지 않는다. 타임테이블 칸의 "겹침"과 내 일정 목록의 "다른 찜과 겹침" 배지를 지웠다. 이제 쓰지 않는 `findConflicts` 와 그 테스트, 스타일도 지웠다. 확인: 테스트 145개, 375px 에서 시간이 겹치는 찜 두 개(펜타포트 7/31 나상현씨밴드·노이)를 넣고 표와 내 일정 모두 표시가 없는 것을 확인했다.
- **펜타포트 2026 지도·체크리스트(사용자 지시, 같은 날)**
  - 수집: 인스타 @pentaportrf 를 로그인 없이 열면 최근 12개(8월 이후)만 보이고, 스크롤해도 더 나오지 않았다. 웹 검색도 개별 게시물을 찾지 못했다. 공식 홈페이지 공지 게시판이 인스타 글(본문과 이미지)을 그대로 올리고 있어서, 2026 글 32개의 본문을 페이지 안에서 키워드로 걸렀다. 토큰을 아끼려고 일치한 글의 제목과 이미지 수만 꺼냈다. 결과는 MAP(입장 동선 안내와 행사장 안내도, 한/영 4장)과 CHECKLIST(10장)였다. "유의사항" 에 일치하는 글은 없었다. 앱이 인스타에서 직접 자동으로 가져오는 것은 로그인, 이용약관, 서버 문제로 하지 않는다(관리자 작업으로 수집).
  - 지도: 행사장 안내도는 비스듬히 그린 입체 그림이라 GPS 를 맞추기 어렵다. 그래서 역, 도로, 건물이 나오는 입장 동선 안내(한국어)를 지도로 썼다. 그림은 약 20° 돌아가 있고 거리가 군데군데 줄어 있어서, 회전과 확대만으로는 10–30 m 가 어긋났다. 실제 위치와 확실히 맞는 기준점 5곳을 정확히 지나는 thin-plate spline 으로 그림을 폈다. 기준점은 역 출구 3개의 가운데, 야구장, 랜드마크 푸르지오시티, 한라 웨스턴파크, KB 스테이지(OSM 의 공원 '대공연장')다. 기준점 오차는 0 m 이고 그 사이는 부드럽게 휜다.
  - 스스로 내린 판단: 역 출구를 하나씩 기준점으로 잡으면 역 그림이 찌그러져서, 역은 한 점으로만 맞췄다. 실제 출구 1·3·4번은 OSM 좌표로 핀을 따로 그렸다. KB 스테이지가 대공연장 자리라는 것은 가정이다(현장 확인 TODO). 그림 밖 빈 곳은 흰색이고, 지도 배경색도 흰색으로 맞췄다(지도 메타에 `background` 추가).
  - 핀: 스테이지 3곳, 게이트 1·2, 물품검색존, 티켓부스 1·2, 셔틀 승하차장은 그림에서 읽은 위치를 같은 변환으로 좌표로 바꿨다(그림에 이름표가 있어 지도에는 안 그리고 목록에만 둔다). 이전의 공원 중심 '행사장' 핀과 4번 출구 하나짜리 핀은 이것으로 바꿨다.
  - 체크리스트와 행사장 안내도: 정보 탭에 공식 이미지를 그대로 옆으로 넘겨 보게 했다(스크롤 스냅). 마우스는 끌어서 넘기고, 화살표와 "n / 10" 표시가 있다. 이미지마다 화면 낭독기용 설명(alt)을 붙였다. 이미지는 webp 로 바꿔 1.5 MB 이고, 설치 때 미리 받지 않고 처음 볼 때 캐시한다. 한국어판만 넣었다.
  - 확인: 테스트 152개, 빌드 통과. 지도는 OSM 도로와 출구 위에 겹쳐서 확인했다. 375px 앱에서 지도, 출구 핀, 체크리스트 넘기기(끌기와 화살표)를 확인했다.

  - 디자인의 무대 머리 오른쪽 별은 무엇을 하는 버튼인지 정해지지 않아 넣지 않았다.
  - 세리프 글꼴은 새로 받지 않고 기기 기본 세리프(Georgia 등)를 쓴다(글꼴 다운로드를 늘리지 않으려고).
  - 메인 컬러는 날짜·하단 탭·별 버튼 외에 관리 탭의 선택 버튼, "보는 중" 표시와 띠, 지도에서 켜진 버튼, 주 버튼에도 쓴다. 관리자 페이지는 그대로 잉크색이다.
- 확인: 테스트 164개, 빌드 통과. 375px 에서 GMF(시각을 10/17 17:00 으로 바꿔 공연 중·10분 후·지금 선), 다크 모드, 관리·정보 탭, 펜타포트(3일), 관리자 페이지 타임테이블을 화면으로 확인했다. 실기기 확인은 아직이다.

**펜타포트 시안 수정과 무대 이름 크기 (사용자 요청)**
- 펜타포트 시안: 제목 오른쪽 그림은 번개·반짝이를 빼고 빨간 별 로고만 남긴다(사용자 지시). 메인 컬러 딥 퍼플, 무대 아이콘·색(KB 노란 별, 몬스터 초록 번개, 스탠리 짙은 초록 텀블러)은 첫 시안 그대로. 앱에는 아직 넣지 않았다.
- 무대 이름이 칸 밖으로 삐져나가지 않게 해 달라는 요청을 앱의 무대 머리에도 적용했다. 무대 머리 카드를 크기 컨테이너로 두고, 글자 크기를 카드 폭에 맞춰 줄인다(375px 약 12.4px, 360px 11.6px, 320px 9.5px). 가장 긴 단어("MONSTER", "KB국민카드")의 Georgia 폭(5.6em)을 실제로 재서 정했다. 단어는 띄어쓰기에서 먼저 줄을 바꾼다. 아이콘은 16px 로 줄였다.
- 확인: 320·360·375px 에서 펜타포트 무대 이름이 단어 중간에서 끊기지 않는 것을 측정으로 확인했다.
